# Meu-app

Projeto gerado pelo GitHub Copilot Chat Assistant: Vite + React + TypeScript + Tailwind + React Router + Jest

Comandos:

- npm install
- npm run dev — iniciar em desenvolvimento
- npm run build — build para produção
- npm run preview — pré-visualizar build
- npm run test — rodar testes
- npm run lint — rodar ESLint
- npm run format — formatar com Prettier

Observações:

- Rode `npx tailwindcss init -p` se quiser regenerar os arquivos de configuração do Tailwind.
